## Affected Pages/Routes
- `/pages/home/index` — 首次进入、品牌说明、免责声明入口
- `/pages/write/index` — 写信、草稿保存、发送校验
- `/pages/sent/index` — 发送成功后的等待态与预计回信时间
- `/pages/inbox/index` — 收件箱状态、空态、刷新
- `/pages/reply-detail/index` — 回信正文展示、异常兜底
- `/pages/profile/index` — 个人信息与使用记录入口
- `/pages/settings/index` — 边界提示、隐私说明、草稿清理

## Key Interactions to Verify
- 首次进入后，用户必须先看到并确认边界说明，才能进入写信流程
- 在写信页输入正文后，草稿会被自动保存，并在重新进入页面时恢复
- 空正文、超短正文、重复点击发送都不会触发重复提交
- 发送成功后会进入等待页，不会直接伪造“即时回信”
- 收件箱能正确展示 `waiting` 和 `ready` 两种状态
- 回信详情页在接口异常或字段缺失时，会展示明确兜底提示

## Edge Cases
- 弱网下发送接口超时，但服务端实际上已成功入库
- 本地草稿数据损坏或字段结构变化
- 收件箱返回空数组
- 回信详情页传入无效 id
- 用户未确认边界说明，尝试直接访问写信页

## Critical Paths
- 首次访问 -> 阅读并确认说明 -> 写信 -> 发送成功 -> 等待回信 -> 在收件箱看到状态变化
- 已有草稿 -> 返回写信页 -> 恢复草稿 -> 继续编辑 -> 发送
- 收件箱有新回信 -> 进入详情页 -> 正确展示正文与纪念时间
